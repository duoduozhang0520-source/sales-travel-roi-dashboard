# 渠道业务部-分贝通差旅看板

独立开发的静态经营分析看板，通过 GitHub Pages 发布，不依赖第三方低代码平台。

- 数据范围：随多维表底表同步更新，当前截至 2026 年 6 月
- 数据源：飞书多维表格中的“渠道业务部分贝通明细”“差旅额度”“用车额度”“渠道城市经理月度回款”
- 费用口径：差旅包含酒店、国内机票、火车；用车包含打车费用
- 金额口径：企业支付金额，已包含退款、退票等负向冲减
- 额度口径：1–4 月按月展示；5–7 月使用二季度整体额度，截至 6 月仅累计 5–6 月实际消费
- 回款口径：1–6 月城市经理回款与目标
- 页面数据：`data.json`
- 入口文件：`index.html`

后续更新时，导出新的多维表格工作簿，运行数据整理与页面生成脚本后即可发布。
